一组可以在手机浏览器里直接玩的小游戏，打开网页即玩，不用安装任何东西，手机和电脑都支持。首页可以自由切换游戏。

## 🎓 四川麻将 · AI 学习教练

这一个和下面的「血战到底」不是一回事：那个是**游戏**，这个是**学习软件**。
它要回答的只有一个问题——

> 你打完一局以后，能不能真正知道自己哪里打错了，以及下一次应该怎么打？

所以这里的每个功能都围着「学会」转，而不是围着「好玩」转。

### 学习闭环

```
打一局 → 发现问题 → 解释原因 → 生成训练 → 完成训练 → 再次实战 → 重新评估
```

### 五个页面

- **首页**：开始陪练 / 今日训练 / 最近复盘 / 我的弱项
- **陪练**：麻将桌 + 教练提示，四种教学模式
- **复盘**：把牌局倒回任意一步，关键节点摆牌对比
- **训练**：今日训练、四类专项课程、错题本
- **我的**：学习数据、错误画像、学习历史

### 打断了可以接着打

每走一步都把「种子 + 动作日志」存一次（一局不到 2KB）。手机来个电话、手滑刷新、误触退出，回到首页会看到「上一局还没打完」，点进去把动作重放到中断那一刻接着打。实测续打后牌河与牌墙张数和中断前完全一致。

### 看不懂的词随时查

教练说「一向听、进张最宽」，新手是懵的——一个教学产品如果默认用户已经懂术语，那它教的只是已经会的人。所以内置 **31 条术语表**，每条都有：一句话定义、一个具体例子、为什么要懂它。牌桌、训练、我的三处一键打开，可搜索。

### 教学模式

| 模式 | AI 做什么 |
| --- | --- |
| 自由模式 | 不提示，想问的时候自己点教练 |
| 轻提示 | 只在明显打错时提醒一句「这一步值得再考虑」，但**不拦你** |
| 教练模式 | 每个关键决策都可以问「该打哪张、为什么」，手牌上还会标出最优解 |
| 考试模式 | 全程不提示，打完统一评分复盘 |

### 它到底教什么

- **定缺**：不是「哪门少缺哪门」。系统对三门各做一次完整推演，比较「打掉这门之后，剩下两门离听牌还有多远」，然后把理由讲给你听。很多时候张数最少的那门恰恰不该缺。
- **换三张**：换出去的三张是否拆了已成形的面子、剩下的牌还差几张听牌、换牌方向和定缺是否一致。
- **牌效率**：向听数、进张数、搭子类型（两面/坎张/边张）、孤张、听牌宽度、听牌番数——每条建议都给具体数字，比如「打 7 万还有 12 张进张，打 9 万只剩 4 张」。
- **防守**：现物、缺门、筋牌、壁牌、幺九——每个危险度判断都说得出依据，而且**明确告诉你这是推测**，因为教练也看不到别人的手牌。

### 四档 AI 陪练

分档靠的是**决策深度**，不是随机走牌——随机 AI 不像人，你也学不到东西。

| 档位 | 会算什么 | 会犯什么错 |
| --- | --- | --- |
| 新手 | 只看单张牌好不好看 | 哪门少缺哪门、见碰就碰、舍不得拆对子 |
| 初级 | 会算向听数 | 不数牌、不防守 |
| 中级 | 向听 + 进张 + 数牌 | 防守比较粗糙 |
| 高级 | 再加番型规划、弃和判断、杠的风险评估 | —— |

400 局自测下来净得分是 `高级 > 中级 > 初级 > 新手`，分档是真的有效（`npm run mj:sim` 可以自己跑）。

勾上「三家水平错开」，对手会变成**低一档 / 本档 / 高一档**，更像真实牌桌——你会看到同一张牌新手碰了、高手没碰，这本身就是教学素材。牌桌上每家的名牌会标出档位。

### 复盘报告

一局打完自动生成，包含：基本数据、**关键节点**、做得好的地方、下一步练什么。

关键节点是**挑出来的**，不是把三四十步全列一遍——按「亏了多少」排序、同类错误最多留两个、总共最多五个。每个节点都摆出「你的选择 vs 可以考虑」两张牌，配原因和一句大白话，还能一键把牌局倒回那一刻。

### 训练系统

题目是**按种子生成 + 用分析层验证**的，不是手写题库：

- 答案由同一套分析层算出来，和实战里的建议永远一致
- 每道题都要求最优解和次优解拉开足够差距，模棱两可的题会被自动丢掉重出（难度就是靠这个差距阈值调的）
- 出题优先级：错题本到期的 → **你上一局真实打错的那一手** → 画像里最弱的一项

专项课程：基础（认识牌 / 基本规则 / 胡牌条件）、进阶（换三张 / 定缺 / 牌效率 / 舍牌）、战术（听牌 / 杠 / 防守）、实战（中盘 / 血战 / 残局）。

**难度会自己校准。** 每一课单独记一个 1~3 的难度值：做对了 +0.15，做错了 −0.25。这个不对称是故意的——它让难度稳定收敛在**正确率 62.5%** 附近（平衡点满足 `p×0.15 = (1-p)×0.25`）。全对说明题太简单学不到东西，错太多只会打击人。样本少于 4 题时不动，拿两三题调的是噪声不是水平。

### 进步曲线

画像回答「我现在哪里弱」，进步曲线回答「我比一个月前强了没」——后者才是让人第二周还愿意打开的东西。

衡量标准用**每局的决策正确率**，不是胜率：麻将单局运气太大，胜率要几百局才有意义；而「这一局里有多少步是最优解」十几局就能看出趋势，而且它直接对应我们教的东西。

图上两条线：每局一个点（原始数据，噪声大）+ 5 局滚动平均（趋势看它）。共用一个纵轴，**不做双轴**。配色经 CVD 校验（ΔE 15.6），两条线还各自有不同笔触和直接标注，不靠颜色单独承载信息。下面另附前后对比：

> 最近 6 局的决策正确率是 93%，比之前高了 25 个百分点——在进步。
> ↑ 舍牌效率：每局少错 5.5 次

### 错误画像

七个维度（定缺、换三张、舍牌效率、听牌判断、防守、杠、碰）各自记星级，但**星级只是外壳**。真正给你看的是这一句：

> 你最近 10 局里，有 6 局在**舍牌效率**上出问题（共 14 次）。

样本不够（少于 12 次）时一律显示三星并明说「数据还不够」——拿三局就给人定性比不定性更糟。

## 🏗 这个学习软件是怎么搭的

### 规则配置层（最重要的一条架构约束）

四川麻将**没有全国统一规则**。成都 / 绵阳 / 重庆、各家线上平台，换三张方向、起胡番数、杠分、查花猪赔法都不一样。所以规则只能写在 `src/mjcoach/rules/config.ts` 一个地方，别处一律从配置读。

内置三套方案，可以用 `registerVariant()` 继续加：

| 方案 | 说明 |
| --- | --- |
| 成都血战到底 | 默认。换三张 + 定缺 + 血战到底，倍数制封顶 64，带呼叫转移与查大叔查花猪 |
| 血流成河 | 胡了继续打，每家最多胡 3 次，摸完牌墙才结束 |
| 教学简化版 | 不换三张、一家胡即结束、不罚花猪，番型只留最基础的四种，专给新手入门 |

每一条「各地打法不同」的规则，都在 `DIVERGENCES` 里登记了分歧点和各方案的取值，`npm test` 会把这张表打出来。**不硬编码成「唯一正确」，也不把两套规则混着用。**

### 分层

```
真实牌局
   ↓
规则引擎（Mahjong Rule Engine）   ← 唯一的裁判，确定性、动作驱动
   ↓
局面分析（向听 / 进张 / 搭子 / 危险度 / 合法动作）
   ↓
结构化分析结果（Structured Facts）  ← 一道闸门
   ↓
AI 教学层（Teaching Layer）
   ↓
自然语言解释
```

两条硬约束：

1. **AI 不判断规则。** 发牌、摸打、碰杠胡、定缺、血战、番型、计分，只有规则引擎说了算。AI（包括语言模型）只能从引擎给出的合法动作里选。
2. **教学层只能看见「结构化事实」。** 它看不到引擎内部，更看不到别人的手牌，所以编不出东西来。数据里没有的，必须回答「当前信息不足，无法确定」——这条有测试守着。

### 完整牌局回放

引擎里一次 `Math.random()` 都没有，洗牌走种子。**种子 + 动作日志**就能把一局牌逐张重放出来，所以牌谱只存这两样（一局不到 2KB）。复盘倒回任意一步、从真实牌局出题，靠的都是它。

### AI 服务：Key 不进前端

- 默认走 **Mock 教练**：本地模板 + 规则引擎算出来的事实。它不是占位符，是正式功能——数字本来就是算出来的，模板只负责串成句子。**没有任何后端也能完整使用全部功能。**
- 想接真模型：设 `VITE_MJ_COACH_API` 指向**你自己的后端**，后端保管密钥并转发。前端代码里没有任何地方接受 `apiKey` 参数，这是故意的。后端只需实现两个接口：

  ```
  POST {base}/explain  → { headline, body, simple? }
  POST {base}/chat     → { headline, body, simple? }
  ```

  发过去的只有算好的事实（向听、进张、危险度、对比结论），不含密钥，也不含别人的手牌。

  **`server/` 目录里有一份可直接运行的示例**（约 120 行）：用 `claude-opus-5`，
  返回格式用 Zod schema 锁死成 `{headline, body, simple}`，系统提示打了缓存标记，
  自带 CORS、限流和体积上限。跑法见 `server/README.md`。

### 命令行里的教练

```bash
npm run mj:why                                                    # 跑内置示例
npm run mj:why -- "234567m 34578s 99s 2s" --lack p                # 自己的牌
npm run mj:why -- "234567m 34578s 99s 2s" --lack p --seen "6s6s6s6s 9s9s"
```

和 App 里教练调的是**同一套分析层**，逐张列出打完之后的向听、进张、剩余张数、危险度。内置示例里有一个专门演示「数牌把答案整个翻过来」：

```
不数牌：        打 2条 → 听 6条 9条          ← 最优
6 条四张见光后： 9条  听牌  剩6张 ███  听 2条(3) 5条(3)   ← 最优变成这个
                2条  听牌  剩0张 ···  听 6条(0) 9条(0)  ← 死听！
```

### 数据是你的

「我的」页可以把学习档案和全部牌谱导出成一份 JSON，换设备、清缓存之前带走；导入会覆盖当前数据，所以有二次确认。所有数据只存在这台设备的浏览器里，不会上传。

### 测试

```bash
npm test        # 272 条：规则 / 分析 / AI / 教学 / 复盘 / 训练 / 画像 / 难度校准 / 进步曲线
npm run mj:sim  # AI 对局模拟：合法性 + 四档强弱验证
npm run mj:why  # 舍牌分析（也可当分析层改动后的人工抽查）
```

`npm test` 的输出就是产品要求的那张表——**规则名称 / 测试案例 / 预期结果 / 实际结果 / PASS·FAIL**，末尾附规则方案对照和规则分歧登记表。

重点覆盖：换三张、定缺、摸打、碰、杠（暗/明/补）、胡、一炮多响、抢杠、血战/血流、流局、查大叔查花猪、番型与封顶、三套规则配置的差异，以及边界情况（最后一张牌、多家同时可动作、已胡玩家、牌墙不足不能杠）。另有 500 局随机与 AI 对局，逐步校验张数守恒、分数守恒、无非法动作。

## 🀄 四川麻将 · 血战到底

一张 3D 绿呢麻将桌：立体麻将牌（万/条/筒牌面全部程序化绘制）、三家牌背环坐、弃牌面朝上摆在桌心，摸牌/出牌/碰杠都有动画。规则为四川血战到底，和 3 个 AI 打一圈。

- **定缺**：开局按提示选一门缺（按钮上标了每门张数），胡牌时手里不能有缺门牌；有缺门牌时必须先打缺门。
- **出牌**：点一下手牌选中（浮起），再点一下打出。
- **碰 / 杠**：别人打出你需要的牌时会弹出按钮；暗杠、明杠都支持，杠了补摸（杠上花翻倍）。
- **血战到底**：胡了的家亮牌退出，其余继续打，直到三家胡牌或摸完牌墙；支持一炮多响。
- **番型**：平胡 / 对对胡 / 清一色 / 七对 / 龙七对 / 金钩钓 / 根 / 自摸 / 杠上花，倍数制计分，结算面板逐家列明。

## ♟️ 中国象棋 · 3D 对弈

一副真正立体的象棋：程序化木纹棋盘（网格、九宫、兵炮位标记、楚河汉界）、圆柱刻字棋子、实时阴影。玩家执红先行，对手是 alpha-beta 搜索的 AI。

- **点自己的棋子**选中（棋子会浮起），棋盘上会标出所有合法落点——绿点可走、红圈可吃。
- **走子/吃子都有动画**：走子弧线滑行，被吃的子翻滚着飞出棋盘。
- **将军**时被将的一方主帅脚下会闪红圈并提示"将军！"。
- 支持**悔棋**（退回你上一步之前）和**重开**；将死或困毙即分胜负。
- 完整规则：马蹩腿、象塞眼不过河、士帅不出九宫、兵过河横走、将帅不可对脸。

## 🎤 唱吧减压 · 学唱歌

给上班压力大的人：把压力唱出去，顺便把歌练好。需要允许**麦克风**权限（声音只在本机分析，不会上传）；拒绝麦克风时仍可用「欣赏模式」听旋律跟着哼。

### 四个玩法

0. **🎯 高音训练营** —— 专治「高音上不去、一唱就费嗓」。
   - **21 条专业练声曲**，全是声乐课上真用的那些：嘟嘴、弹舌、吸管发声、哼鸣、警笛滑音、小狗哼唧、咕音琶音、真假声翻转……每条都写清楚**怎么做**、**为什么有用**、**最容易做错哪里**，不用专业术语。
   - **30 天课程**，分四个阶段：省力发声 → 找到头声 → 打通换声 → 混声高音。每天 3~4 条，几分钟。
   - **自动模进**：像老师弹琴一样，一条音型跟一遍就升半音，一直到你唱不动为止自动停——不会让你硬顶。
   - **费嗓预警**（这个是别家没有的）：实时判断你是在唱还是在喊。检测破音、声音发抖、越唱越响、漏气，屏幕上一条状态条从绿变红，并直接告诉你「有点在喊了，同样的音高试着唱得更小声」。
   - **音域成长曲线**：每天记录你唱到的最高音，画成折线，看得见自己在涨。
   - 累了随时点「⬇ 降两个音」或「⏭ 这条够了」。练习库里带 🌱 的是半闭合练习，几乎不伤嗓，嗓子累时只做这些。

1. **🫁 减压开嗓**
   - **引导呼吸**：跟着圆圈「吸气 4 秒 → 屏住 4 秒 → 呼气 6 秒」做 5 轮，先放松再开口。
   - **音阶开嗓**：跟参考音哼 do-re-mi 五度音阶，一组比一组高半音，实时显示你的音高有没有贴住台阶。
   - **测音域**：唱出你最低和最高的舒服音，App 记住你的音域，跟唱歌曲会按它自动推荐移调。
2. **🎯 音准训练**
   - **单音模仿**：听一个音唱出来并稳住，音准表实时显示偏高/偏低多少音分，唱准拿连击翻倍得分。
   - **声控小鸟**：用声音的高低控制小鸟飞行穿过缺口——唱得高飞得高，停下会下坠。放声乱唱也是一种减压。
3. **🎤 跟唱打分**
   - 二十二首经典公版旋律，按难度排序：
     - **入门**：小星星、两只老虎、新年好、划船歌、玛丽的小羊羔、伦敦大桥、小白菜
     - **简单**：生日快乐、欢乐颂（唱名版）、小蜜蜂、铃儿响叮当、噢！苏珊娜、樱花、红河谷、多年以前
     - **进阶**：茉莉花、送别（片段）、友谊地久天长（唱名版）、平安夜、摇篮曲（片段）、绿袖子、奇异恩典
   - 每首歌卡片上标出**原调下的最高音**；测过音域后还会标「够得着 / 刚好到顶 / 高 N 个半音」，练高音时一眼知道哪首现在能唱。
   - 钢琴卷帘滚动显示音符条和歌词，唱的同时**实时画出你的音高曲线**；唱过的音符绿色=准、红色=跑调，一眼看到问题在哪句。
   - 唱完打分评星（⭐~⭐⭐⭐），每首最高分自动保存；`♭ / ♯` 按钮可 ±6 半音移调找到舒服的调。
   - 唱低八度或高八度都算对（评分按八度折叠），男女生都能直接唱。

### 技术细节

- 音高检测用 **McLeod 风格归一化自相关（NSDF）+ 抛物线插值**，纯 TypeScript 实现、零依赖，检测范围 C2~C6。
- 参考音与伴奏全部用 **Web Audio 实时合成**（八音盒音色），无任何音频文件。
- 音域、每首歌最高分、声控小鸟纪录保存在浏览器 localStorage。

## ⚔️ 手机 MOBA · 一路推塔

一局约 3～6 分钟的单路推塔对战。你操纵一名英雄，带着自动出兵的小兵沿唯一一条兵线推进，逐个拆掉对面的防御塔，最后摧毁**敌方水晶**即获胜；己方水晶被摧毁则失败。对手是一名会推线、越塔、追击和撤退的 AI 英雄。

### 操作（手机 / 电脑）

- **左手虚拟摇杆**：控制英雄走位。
- **英雄自动普攻**：进入攻击范围会自动攻击最近的敌人（优先敌方英雄）。
- **右手四个技能键**：
  - **Q 能量弹** —— 朝当前方向发射穿透弹，命中造成爆发伤害。
  - **W 震荡新星** —— 身周爆发，伤害并减速附近敌人。
  - **E 疾冲** —— 朝当前方向瞬移一段距离，用来追击或逃生。
  - **R 雷霆审判** —— 6 级解锁的大招，对目标区域造成巨额伤害。
- 技能键会显示冷却读秒；法力不足或未解锁时不可释放。

### 核心玩法

- **补刀与经济**：击杀小兵、拆塔、击杀敌方英雄可获得金币，另有少量被动收入。
- **升级**：靠近战场的击杀会给予经验，升级提升生命/攻击并解锁大招（最高 10 级）。
- **装备商店**：点右下角 🛒 打开商店，**回到己方水晶附近**即可反复购买力量水晶、生命宝石、疾速符文、疾行之靴（价格递增）。
- **防御塔机制**：塔会优先攻击小兵，孤身越塔很危险；必须先拆掉靠前的塔，才能攻击后面的塔和水晶。
- **阵亡与复活**：英雄阵亡后会在己方水晶处等待数秒复活，等级越高复活越久。
- 右上角**小地图**实时显示双方水晶、防御塔、英雄与兵线。

## 🏹 塔防远征 · 3D 塔防

下班后开一局，建塔、升级、顶住 25 波进攻，守住你的水晶基地。

1. **选地图、难度和模式** —— 两张地图（蜿蜒山谷、双路汇流），三档难度（简单 / 中等 / 困难），两种模式（标准 25 波 / 无尽模式），难度越高敌人越强、初始金币越少。
2. **建塔** —— 点地图上的灰色空格位，弹出环形菜单，选一种塔建造（会花金币）。
3. **升级 / 出售** —— 点已经建好的塔，可以升级（最高 3 级）或出售回收 60% 金币。
4. **开始波次** —— 点底部黄色按钮放出一波敌人。击杀敌人赚金币，清完一波有奖励。
5. **守住基地** —— 敌人走到终点会扣生命，生命归零就失败；顶住全部 25 波就通关。

### 操作（手机）

- **单指拖动**：平移视角
- **双指捏合**：缩放
- **点空地**：建塔
- **点塔**：升级或出售
- 右上角可 **暂停** 和切换 **x1 / x2 速度**

### 四种防御塔

| 塔 | 特点 |
|---|---|
| 🏹 箭塔 | 攻速快、单体，性价比高的基础输出 |
| 💣 炮塔 | 范围溅射，克制成群小怪（打不到飞行兵） |
| ❄️ 冰霜塔 | 命中减速，控制型，配合输出塔很强 |
| ⚡ 闪电塔 | 高伤害、攻速慢，专治重甲兵和 Boss |

五种敌人：普通兵、快速兵（快而脆）、重甲兵（血厚慢速）、飞行兵（走直线捷径，只有能对空的塔打得到）、Boss（每 5 波一个，血量极高）。

### 两种模式

- **标准 25 波**：顶住 25 波（含 Boss 波）即通关。
- **无尽模式**：波次永不结束、敌人越来越强，比谁撑得久，单独记录每张地图每个难度的最高波数。

### 更多细节

- **每波守住后随机奖励**：除固定清波金币外，还会抽一个随机奖励——金币补给 / 巨额宝箱 / 战争红利（存款利息）/ 武器强化（全塔永久增伤）/ 基地维修 / 免费升级。
- **音效**：全部用 Web Audio 实时合成（无音频文件）——建塔、开火、击杀、清波、胜负都有反馈，右上角 🔊 可随时静音。
- **打击特效**：命中溅火花、击杀迸碎片，Boss 死亡爆得更夸张。

进度（每张地图每个难度的通关状态、标准最高波数、无尽最高波数）会自动保存在浏览器里。

## 本地运行

需要 Node.js 18+。

```bash
npm install     # 安装依赖
npm run dev     # 本地开发，浏览器打开提示的地址
npm run build   # 构建生产版本到 dist/
npm run preview # 预览构建结果
```

## 技术说明

- **首页 / MOBA**：纯 **Canvas 2D** 俯视渲染，无任何外部图片或模型文件，完全自包含；较重的 3D 塔防按需（动态 import）加载，因此进入首页和 MOBA 时不会下载 Three.js。
- **塔防远征**：用 **Three.js** 做 3D 渲染，所有模型都是用几何体程序化生成的低多边形风格；音效用 Web Audio 实时合成。
- **Vite + TypeScript** 开发和构建，产物是纯静态文件；进度用 **localStorage** 保存。
