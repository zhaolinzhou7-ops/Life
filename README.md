## 🎧 AI 唱歌教练 · 学唱歌

不是 K 歌软件，也不是唱歌评分器。它要回答的是四个问题：

1. 我唱歌**哪里**不好？
2. **为什么**不好？
3. 接下来该**练什么**？
4. 练了以后**到底有没有进步**？

需要允许**麦克风**权限。所有分析都在你这台设备上完成，没有服务器，也没有账号。

### 核心闭环

```
选歌 → 跟唱 → 录音 → 分析 → 发现问题 → AI 解释 → 专项训练 → 再唱一遍 → 前后对比
```

### 它会告诉你什么

唱完一首，你看到的不是「82 分」，而是：

- **目标音高 vs 你的实际音高**——一张按偏差着色的曲线图。绿=准、黄=有点偏、红=明显偏，
  一眼看出自己是唱高了还是唱低了，以及高/低在哪一句。
- **逐音复盘**——每个音一个色块，点红色的能看到：目标是什么音、你唱成了什么、
  偏了多少音分、起拍早了还是晚了多少毫秒，可以试听目标音，也可以只听你唱的那半秒。
- **四项音准指标**，每一项都带「为什么是这个结果」：
  音准（平均偏多少音分）、命中率（多少比例的时间落在 ±50 音分内）、
  稳定性（长音过程中音高飘多少）、高音稳定度（高音区单独拿出来看）。
- **节奏**：入拍一致性、节奏稳定度、抢拍/拖拍次数、句尾是早收还是拖长。
- **音域**：这次唱到的范围与舒适区，和这首歌要求的音域画在一起，够不够得着一目了然。
- **AI 教练**：五段式——好在哪 → 最大的问题 → 为什么会这样 → 怎么练 → 下次目标。

### 一些刻意的设计

**指标可以是「评不了」。** 长音不够两个就不给稳定性分，高音不到三个就不评高音区，
自由演唱没有目标旋律就不给音准分——并且明说为什么。宁可说测不了，也不给一个假数字。

**没有可靠节拍就不下精确结论。** 用户自己导入的音频没有节拍标注，这时节奏分析自动降级，
只做基础统计并告知原因。

**抢拍/拖拍和设备延迟分得开才说。** 蓝牙耳机常有 100~300 毫秒延迟，
不校准的话「你在拖拍」和「你的设备慢了」在数学上没法区分。所以未校准且整体偏移大时，
只给与延迟无关的一致性指标，并提示去做一次十秒的自动校准（外放几声「哒」同时录音即可）。

**不许说套话。** AI 的输出要过一道校验：五段齐全、问题带具体数字、目标可验证、
练习必须指向真实存在的条目；出现「很有潜力/继续努力/感情很丰富」这类话直接判不合格，
回退到内置教练，并告诉你为什么回退。

### 专项训练

15 条练习，分四类。每条都写清楚**怎么做**、**为什么有用**、**最容易做错哪里**。

- **音准**：单音模唱、大调音阶、音程模唱、音高跟踪、长音保持
- **节奏**：节拍跟随、节奏模仿、入拍训练
- **高音**：渐进音阶（五度模进）、半音上行、小范围音域扩展、轻声高音
- **稳定性**：长音稳定、持续时间、音量稳定

练习的打分用的是和唱歌完全相同的那套分析代码，所以练习成绩和演唱成绩可比——
练习分数涨了，回去唱歌的分数才应该跟着动。高音类练习连续两步唱得吃力会自动停下来：
高音是一点点累积上去的，硬顶只会让明天更差。

### 今日训练与进步曲线

训练计划读的是你最近五次演唱**真实暴露出来的问题**，每一条都写明「为什么给你这条」，
最后一项永远是「再唱一遍同一首歌」——那是闭环里的「再检测」。

进步页主角不是折线，而是「第 1 次 → 第 5 次 → 第 10 次」的对比表。
变化不到 3 分就直说「属于正常波动，还看不出趋势」。

### 曲库与版权

只收录**公有领域**的旋律，由我们按简谱重新编配成单声部简化版，伴奏由 Web Audio 实时合成，
不含任何录音制品。每首歌的卡片上都标着来源。

想练流行歌，用「唱我自己的」——只分析你的嗓音（音域、长音稳定度、动态范围、录音质量），
不需要也不提供原曲。

### 隐私

- **录音默认不保存。** 唱完分析完，离开页面就没了。想留下来要自己按「保存这次录音」，
  也可以设成保留 7 天 / 30 天，过期的每次打开应用时自动清掉。
- 存档里只有指标，没有音频。
- 配了 AI 之后，发出去的只有**指标和问题清单**——也就是分析页上已经显示给你看的那些数字。
  录音本身、逐帧音高轨迹、设备信息都不会发送。API Key 只存在你的浏览器里。
- 「我的 → 设置」里可以一键删除全部本地数据。

### 这个应用不能做什么

写在设置页正文里，不藏在条款里：

- **不能**判断声带健康、声带闭合、喉部或呼吸系统的状况。这些需要专业检查，
  一段手机录音得不出来。嗓子不舒服请看医生。
- **不能**保证练了就一定能唱到某个音。
- 这里的评分**不等同于**专业声乐老师的评估，也不是任何等级认证。
  它们是软件内部的训练指标，用来和你自己的过去比。

### 换 AI 模型

默认是内置教练（规则引擎），不联网也完全可用。想换成大模型，在「设置 → AI 教练」里选：
Claude、OpenAI、DeepSeek、Kimi、豆包方舟、本机 Ollama / LM Studio，或者任何 OpenAI 兼容接口。
用你自己的 API Key。业务代码只认一个 `AIProvider` 接口，厂商不进业务逻辑。

### 技术分层

```
Audio Input      audio/recorder.ts    AudioWorklet 取原始 PCM
Audio Processing dsp/resample.ts      高通、抗混叠低通、重采样
Pitch Detection  dsp/pitch.ts         MPM（NSDF + 抛物线插值），自相关走 FFT
Feature Extract  dsp/features.ts      RMS/动态范围/削波/信噪比/谱质心/谱平坦度
Rhythm Analysis  analysis/rhythm.ts   入拍偏差、抢拍拖拍、句尾、延迟校准
Performance      analysis/*.ts        音准/稳定性/音域/质量 → 结构化「发现」
Teaching Layer   ai/*.ts              Provider 抽象 + 提示词 + 反废话校验 + 规则兜底
User Profile     data/profile.ts      能力五维、进步趋势
Recommendation   data/plan.ts         今日训练计划
```

算法层负责算数，AI 层只负责解释——不让 LLM 去替代音频算法。

### 开发

```bash
npm install
npm run dev          # 本地开发
npm run typecheck    # 类型检查
npm run test:vocal   # 算法测试（合成音频，181 项）

```

测试断言应用确实把它找出来了。


## 🎤 唱吧减压 · 学唱歌

给上班压力大的人：把压力唱出去，顺便把歌练好。需要允许**麦克风**权限（声音只在本机分析，不会上传）；拒绝麦克风时仍可用「欣赏模式」听旋律跟着哼。

### 四个玩法

0. **🎯 高音训练营** —— 专治「高音上不去、一唱就费嗓」。
   - **21 条专业练声曲**，全是声乐课上真用的那些：嘟嘴、弹舌、吸管发声、哼鸣、警笛滑音、小狗哼唧、咕音琶音、真假声翻转……每条都写清楚**怎么做**、**为什么有用**、**最容易做错哪里**，不用专业术语。
   - **30 天课程**，分四个阶段：省力发声 → 找到头声 → 打通换声 → 混声高音。每天 3~4 条，几分钟。
   - **自动模进**：像老师弹琴一样，一条音型跟一遍就升半音，一直到你唱不动为止自动停——不会让你硬顶。
   - **费嗓预警**（这个是别家没有的）：实时判断你是在唱还是在喊。检测破音、声音发抖、越唱越响、漏气，屏幕上一条状态条从绿变红，并直接告诉你「有点在喊了，同样的音高试着唱得更小声」。
   - **音域成长曲线**：每天记录你唱到的最高音，画成折线，看得见自己在涨。
   - 累了随时点「⬇ 降两个音」或「⏭ 这条够了」。练习库里带 🌱 的是半闭合练习，几乎不伤嗓，嗓子累时只做这些。

1. **🫁 减压开嗓**
   - **引导呼吸**：跟着圆圈「吸气 4 秒 → 屏住 4 秒 → 呼气 6 秒」做 5 轮，先放松再开口。
   - **音阶开嗓**：跟参考音哼 do-re-mi 五度音阶，一组比一组高半音，实时显示你的音高有没有贴住台阶。
   - **测音域**：唱出你最低和最高的舒服音，App 记住你的音域，跟唱歌曲会按它自动推荐移调。
2. **🎯 音准训练**
   - **单音模仿**：听一个音唱出来并稳住，音准表实时显示偏高/偏低多少音分，唱准拿连击翻倍得分。
   - **声控小鸟**：用声音的高低控制小鸟飞行穿过缺口——唱得高飞得高，停下会下坠。放声乱唱也是一种减压。
3. **🎤 跟唱打分**
   - 二十二首经典公版旋律，按难度排序：
     - **入门**：小星星、两只老虎、新年好、划船歌、玛丽的小羊羔、伦敦大桥、小白菜
     - **简单**：生日快乐、欢乐颂（唱名版）、小蜜蜂、铃儿响叮当、噢！苏珊娜、樱花、红河谷、多年以前
     - **进阶**：茉莉花、送别（片段）、友谊地久天长（唱名版）、平安夜、摇篮曲（片段）、绿袖子、奇异恩典
   - 每首歌卡片上标出**原调下的最高音**；测过音域后还会标「够得着 / 刚好到顶 / 高 N 个半音」，练高音时一眼知道哪首现在能唱。
   - 钢琴卷帘滚动显示音符条和歌词，唱的同时**实时画出你的音高曲线**；唱过的音符绿色=准、红色=跑调，一眼看到问题在哪句。
   - 唱完打分评星（⭐~⭐⭐⭐），每首最高分自动保存；`♭ / ♯` 按钮可 ±6 半音移调找到舒服的调。
   - 唱低八度或高八度都算对（评分按八度折叠），男女生都能直接唱。

### 技术细节

- 音高检测用 **McLeod 风格归一化自相关（NSDF）+ 抛物线插值**，纯 TypeScript 实现、零依赖，检测范围 C2~C6。
- 参考音与伴奏全部用 **Web Audio 实时合成**（八音盒音色），无任何音频文件。
- 音域、每首歌最高分、声控小鸟纪录保存在浏览器 localStorage。

## ⚔️ 手机 MOBA · 一路推塔

一局约 3～6 分钟的单路推塔对战。你操纵一名英雄，带着自动出兵的小兵沿唯一一条兵线推进，逐个拆掉对面的防御塔，最后摧毁**敌方水晶**即获胜；己方水晶被摧毁则失败。对手是一名会推线、越塔、追击和撤退的 AI 英雄。

### 操作（手机 / 电脑）

- **左手虚拟摇杆**：控制英雄走位。
- **英雄自动普攻**：进入攻击范围会自动攻击最近的敌人（优先敌方英雄）。
- **右手四个技能键**：
  - **Q 能量弹** —— 朝当前方向发射穿透弹，命中造成爆发伤害。
  - **W 震荡新星** —— 身周爆发，伤害并减速附近敌人。
  - **E 疾冲** —— 朝当前方向瞬移一段距离，用来追击或逃生。
  - **R 雷霆审判** —— 6 级解锁的大招，对目标区域造成巨额伤害。
- 技能键会显示冷却读秒；法力不足或未解锁时不可释放。

### 核心玩法

- **补刀与经济**：击杀小兵、拆塔、击杀敌方英雄可获得金币，另有少量被动收入。
- **升级**：靠近战场的击杀会给予经验，升级提升生命/攻击并解锁大招（最高 10 级）。
- **装备商店**：点右下角 🛒 打开商店，**回到己方水晶附近**即可反复购买力量水晶、生命宝石、疾速符文、疾行之靴（价格递增）。
- **防御塔机制**：塔会优先攻击小兵，孤身越塔很危险；必须先拆掉靠前的塔，才能攻击后面的塔和水晶。
- **阵亡与复活**：英雄阵亡后会在己方水晶处等待数秒复活，等级越高复活越久。
- 右上角**小地图**实时显示双方水晶、防御塔、英雄与兵线。

## 🏹 塔防远征 · 3D 塔防

下班后开一局，建塔、升级、顶住 25 波进攻，守住你的水晶基地。

1. **选地图、难度和模式** —— 两张地图（蜿蜒山谷、双路汇流），三档难度（简单 / 中等 / 困难），两种模式（标准 25 波 / 无尽模式），难度越高敌人越强、初始金币越少。
2. **建塔** —— 点地图上的灰色空格位，弹出环形菜单，选一种塔建造（会花金币）。
3. **升级 / 出售** —— 点已经建好的塔，可以升级（最高 3 级）或出售回收 60% 金币。
4. **开始波次** —— 点底部黄色按钮放出一波敌人。击杀敌人赚金币，清完一波有奖励。
5. **守住基地** —— 敌人走到终点会扣生命，生命归零就失败；顶住全部 25 波就通关。

### 操作（手机）

- **单指拖动**：平移视角
- **双指捏合**：缩放
- **点空地**：建塔
- **点塔**：升级或出售
- 右上角可 **暂停** 和切换 **x1 / x2 速度**

### 四种防御塔

| 塔 | 特点 |
|---|---|
| 🏹 箭塔 | 攻速快、单体，性价比高的基础输出 |
| 💣 炮塔 | 范围溅射，克制成群小怪（打不到飞行兵） |
| ❄️ 冰霜塔 | 命中减速，控制型，配合输出塔很强 |
| ⚡ 闪电塔 | 高伤害、攻速慢，专治重甲兵和 Boss |

五种敌人：普通兵、快速兵（快而脆）、重甲兵（血厚慢速）、飞行兵（走直线捷径，只有能对空的塔打得到）、Boss（每 5 波一个，血量极高）。

### 两种模式

- **标准 25 波**：顶住 25 波（含 Boss 波）即通关。
- **无尽模式**：波次永不结束、敌人越来越强，比谁撑得久，单独记录每张地图每个难度的最高波数。

### 更多细节

- **每波守住后随机奖励**：除固定清波金币外，还会抽一个随机奖励——金币补给 / 巨额宝箱 / 战争红利（存款利息）/ 武器强化（全塔永久增伤）/ 基地维修 / 免费升级。
- **音效**：全部用 Web Audio 实时合成（无音频文件）——建塔、开火、击杀、清波、胜负都有反馈，右上角 🔊 可随时静音。
- **打击特效**：命中溅火花、击杀迸碎片，Boss 死亡爆得更夸张。

进度（每张地图每个难度的通关状态、标准最高波数、无尽最高波数）会自动保存在浏览器里。

## 技术说明

- **首页 / MOBA**：纯 **Canvas 2D** 俯视渲染，无任何外部图片或模型文件，完全自包含；较重的 3D 塔防按需（动态 import）加载，因此进入首页和 MOBA 时不会下载 Three.js。
- **塔防远征**：用 **Three.js** 做 3D 渲染，所有模型都是用几何体程序化生成的低多边形风格；音效用 Web Audio 实时合成。
- **Vite + TypeScript** 开发和构建，产物是纯静态文件；进度用 **localStorage** 保存。
