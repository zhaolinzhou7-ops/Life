# 塔防远征 · 3D 塔防

一款可以在手机浏览器里直接玩的 3D 塔防游戏。下班后开一局，建塔、升级、顶住 25 波进攻，守住你的水晶基地。

支持 **单人闯关** 和 **联机对战**：两名玩家面对完全相同的波次开打，比谁守得更久、走得更远。

打开网页即玩，不用安装任何东西，手机和电脑都支持。

## 怎么玩

1. **选地图和难度** —— 两张地图（蜿蜒山谷、双路汇流），三档难度（简单 / 中等 / 困难），难度越高敌人越强、初始金币越少。
2. **建塔** —— 点地图上的灰色空格位，弹出环形菜单，选一种塔建造（会花金币）。
3. **升级 / 出售** —— 点已经建好的塔，可以升级（最高 3 级）或出售回收 60% 金币。
4. **开始波次** —— 点底部黄色按钮放出一波敌人。击杀敌人赚金币，清完一波有奖励。
5. **守住基地** —— 敌人走到终点会扣生命，生命归零就失败；顶住全部 25 波就通关。

### 操作（手机）

- **单指拖动**：平移视角
- **双指捏合**：缩放
- **点空地**：建塔
- **点塔**：升级或出售
- 右上角可 **暂停** 和切换 **x1 / x2 速度**

### 四种防御塔

| 塔 | 特点 |
|---|---|
| 🏹 箭塔 | 攻速快、单体，性价比高的基础输出 |
| 💣 炮塔 | 范围溅射，克制成群小怪（打不到飞行兵） |
| ❄️ 冰霜塔 | 命中减速，控制型，配合输出塔很强 |
| ⚡ 闪电塔 | 高伤害、攻速慢，专治重甲兵和 Boss |

### 五种敌人

普通兵、快速兵（快而脆）、重甲兵（血厚慢速）、飞行兵（走直线捷径，只有能对空的塔打得到）、Boss（每 5 波一个，血量极高）。

进度（每张地图每个难度的通关状态、最高波数）会自动保存在浏览器里。

## 联机对战

在主菜单选 **联机对战**，两人即可远程同台竞技：

1. **一方创建房间** —— 选好地图和难度，得到一个 4 位房间码。
2. **另一方加入房间** —— 输入房间码连接。
3. **同波开打** —— 双方拿到**完全相同**的波次序列（由同一随机种子生成，保证公平），各自独立建塔防守。
4. **实时看对手** —— 战斗中顶部会显示对手的剩余生命和当前波数。
5. **决出胜负** —— 谁到达的波次更高谁赢；同波则比剩余生命。对手中途掉线判弃权。

联机完全依赖浏览器点对点连接（WebRTC），信令走 [PeerJS](https://peerjs.com/) 的公共服务器，**不需要任何自建后端**，因此纯静态部署（如 GitHub Pages）也能直接联机。在过于严格的网络环境（某些企业/校园网）下点对点可能无法建立，届时会给出提示。

## 本地运行

需要 Node.js 18+。

```bash
npm install     # 安装依赖
npm run dev     # 本地开发，浏览器打开提示的地址
npm run build   # 构建生产版本到 dist/
npm run preview # 预览构建结果
```

## 技术说明

- **Three.js** 做 3D 渲染，所有模型都是用几何体程序化生成的低多边形风格，不依赖任何外部图片或模型文件，加载快、完全自包含。
- **Vite + TypeScript** 开发和构建，产物是纯静态文件。
- **localStorage** 保存游戏进度。
- **PeerJS / WebRTC** 实现联机对战的点对点连接。采用「同种子同波次 + 各自本地模拟 + 轻量战况同步」的设计：双方各自跑自己的战斗，网络上只传很小的战况快照，天然避免了状态同步与作弊校验的复杂度，也不需要后端。

## 目录结构

```
src/
├── main.ts            入口：首页 / 单人 / 联机 / 战斗 / 结算之间的切换
├── core/
│   ├── game.ts        战斗引擎：场景、渲染循环、规则、交互（可注入联机钩子）
│   ├── wave.ts        波次生成（可传种子，保证联机双方同波）
│   ├── economy.ts     难度与数值配置
│   ├── rng.ts         可复现随机数（联机同波的基础）
│   └── save.ts        进度存档（localStorage）
├── net/
│   ├── peer.ts        PeerJS 点对点连接封装（建房 / 加入）
│   ├── protocol.ts    点对点消息协议
│   └── versus.ts      联机对战流程编排（大厅 → 对局 → 结算）
├── entities/
│   ├── tower.ts       防御塔（4 种 + 升级数值）
│   ├── enemy.ts       敌人（5 种 + 沿路径移动）
│   └── projectile.ts  弹体与命中（溅射 / 减速）
├── maps/maps.ts       地图数据与布局计算
├── render/
│   ├── models.ts      程序化低多边形模型
│   └── camera.ts      俯视相机 + 触屏平移缩放
└── ui/
    ├── hud.ts         战斗内 HUD、建塔菜单、塔面板、对手战况条
    ├── menus.ts       首页 / 选关 / 结算界面
    └── lobby.ts       联机大厅：房间码、加入、对战结算界面
```
